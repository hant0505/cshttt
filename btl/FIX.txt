🟥 5. Vấn đề nhỏ trong code của bạn

Bạn đang copy đoạn:

next_doc_id, entropy = classifier.recommend_document()
while next_doc_id in USERS[user_id]['skipped']:
    next_doc_id, entropy = classifier.recommend_document()


Ở nhiều API.
→ Cách viết bị trùng logic.

🟩 Bạn nên tạo hàm helper chung:
def get_next_valid_doc(user_id):
    classifier = USERS[user_id]['classifier']
    next_doc, entropy = classifier.recommend_document()

    while next_doc in USERS[user_id]['skipped']:
        next_doc, entropy = classifier.recommend_document()

    USERS[user_id]['current_doc_id'] = next_doc
    return next_doc, entropy


Và ở mọi API chỉ cần dùng:

next_doc_id, entropy = get_next_valid_doc(user_id)


→ Gọn, sạch, đúng chuẩn software engineering.
